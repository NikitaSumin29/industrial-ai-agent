# Прототип ИИ-агента для СППР технологических линий

Программный комплекс системы поддержки принятия решений (СППР) для предиктивной диагностики оборудования и генерации рекомендаций оператору в реальном времени.

## Стек технологий
* **Язык:** Python 3.13
* **Менеджер пакетов и окружения:** [uv](https://github.com/astral-sh/uv)
* **Предиктивное ядро (ML):** Scikit-learn, Pandas, NumPy
* **Агентная логика и рассуждения:** Локальная LLM (Ollama / Qwen 3.5 9B) + База технологических регламентов
* **Интерфейс оператора (HMI):** Streamlit

## Архитектура решения
Проект реализует замкнутый контур управления (Human-in-the-loop):
1. **Сбор телеметрии:** мониторинг 5 параметров датчиков (температура, крутящий момент, скорость вращения, износ инструмента).
2. **Предиктивный анализ:** вероятностная классификация предаварийных состояний (HDF, PWF, OSF, TWF) на базе эталонного датасета AI4I 2020.
3. **Логический вывод:** сопоставление типа угрозы с технологическими регламентами цеха.
4. **HMI советчик:** генерация оперативных рекомендаций диспетчеру с замером времени отклика (инференса).

## Быстрый старт (Запуск проекта)

### 1. Клонирование репозитория
```bash
git clone https://github.com/NikitaSumin29/industrial-ai-agent.git
cd industrial-ai-agent
```

### 2. Установка окружения через uv
Проект использует менеджер пакетов `uv`. Все зависимости устанавливаются автоматически:
```bash
uv sync
```

### 3. Запуск локальной LLM
Убедитесь, что установлена [Ollama](https://ollama.com/), и скачана модель в локальное хранилище:
```bash
ollama pull qwen3.5:9b
```

### 4. Обучение предиктивной модели (ML)
```bash
uv run python src/train_model.py
```

### 5. Запуск веб-интерфейса СППР (Streamlit)
```bash
uv run streamlit run app.py
```
После запуска интерфейс автоматически откроется в браузере по адресу: `http://localhost:8501`.
