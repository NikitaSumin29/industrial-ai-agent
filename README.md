# Прототип ИИ-агента для СППР технологических линий

Программный комплекс системы поддержки принятия решений (СППР) для предиктивной диагностики оборудования и генерации рекомендаций оператору в реальном времени.

## Стек технологий

- **Язык:** Python 3.13
- **Менеджер пакетов и окружения:** [uv](https://github.com/astral-sh/uv)
- **Предиктивное ядро (ML):** Scikit-learn, Pandas, NumPy
- **Агентная логика и рассуждения:** Локальная LLM (Ollama / Qwen 3.5 9B) + База технологических регламентов
- **Интерфейс оператора (HMI):** Streamlit

## Архитектура решения

Проект реализует замкнутый контур управления:

1. **Сбор телеметрии:** мониторинг датчиков (температура, крутящий момент, скорость вращения, износ инструмента).
2. **Предиктивный анализ:** классификация предаварийных состояний (HDF, PWF, OSF, TWF) на базе эталонного датасета AI4I 2020.
3. **Логический вывод:** сопоставление типа сбоя с технологическими регламентами цеха.
4. **HMI советчик:** выдача контекстных рекомендаций оператору технологической линии.
